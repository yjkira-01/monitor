# mRI点云融合：多种子、容量与时偏开发核查

日期：2026-10-13。续接原聊天的最后实验计划。本报告的数值来自已完成的真实开发运行，而非方法预期或合成演示。

## 1. 当前结论

**保留点集结构后的普通融合在当前开发集上具有稳定互补性；时序对应候选仍需要更大范围的必要性验证。** 三个初始化种子的正常画面MPJPE为66.144±0.585mm，RGB单路为71.902±2.138mm；参数量相近的RGB对照为72.528±0.701mm。普通融合分别改善8.01%和8.80%。同结构但打乱雷达配对训练的融合为70.235mm。

三个种子的平均结果中，四名验证参与者相较原RGB、容量对照和打乱训练对照均有改善。这支持保留配对点云信息继续研究，不能仅以“多了参数”解释这轮收益，也不能证明已排除所有结构和优化差异。

注入±200ms后恢复对应的平均收益为0.584–1.098mm；±500ms为1.582–2.456mm，比旧统计特征基线更明显，但整体约1–3.5%的恢复量级。它说明当前模型确实受到时偏影响，尚未证明学习时序分布、任务空间方差和复杂门控能胜过简单对齐或退化增强。

因此，当前推进点云融合的可靠性和扩大开发样本；时序候选保留为小规模后续对照，不直接升格为已成立的核心贡献。完整A+B网络、普通注意力/MAP/熵门控对照和正式测试均未完成。

## 2. 本轮确实完成的工作

- 保留原单种子记录；新增独立运行目录，实际完成3种子×5模型共15个训练。
- 训练主体沿用`[1,2,4,7,8,9,11,13,14,15,16,17]`，验证主体`[5,6,19,20]`。主体划分种子固定7；只改变模型初始化7、17、27，**不是三种主体划分**。
- 所有模型同帧比较：训练768、验证256，每人64帧。数据来自先前已校验的视频与独立冻结RTMO提取器；没有使用目标框、目标关键点或另一相机作为推理输入。
- 固定80轮、最后一轮报告；不根据验证结果挑选训练轮次。AdamW、lr=0.001、weight_decay=0.0001、batch64，无增强、正常画面训练。标准化与目标均值仅拟合训练主体。
- 每个种子各模型批次顺序相同，批次随机数与模型初始化独立。旧单种子实验的批次顺序依赖初始化后的全局随机状态，故新seed7不是旧数值的逐位重现；旧结果不覆盖。
- 原公开点云保持XYZ、Doppler、强度，逐点5→32→64，掩码平均/最大聚合；没有时间编码。它仍是作者发布的预处理特征，不是本轮独立复建雷达原始处理。
- 除模型指标外，保存每个模型安全NPZ权重与验证预测；逐模型重载15套权重，独立重算72项预测指标，与JSON误差在1e-10mm容差内一致。

具体设置在结果读取前写入[核查协议](point_validation_protocol_20261013.md)。

## 3. 主要结果

数值为三个初始化种子的均值±样本标准差，单位mm，越低越好。这种标准差描述初始化波动，不是总体泛化置信区间。

| 模型 | 参数量 | 正常画面MPJPE | 像素亮度×0.18 MPJPE |
| --- | ---: | ---: | ---: |
| RGB单路 | 46,259 | 71.902±2.138 | 72.725±1.548 |
| 容量相近RGB | 64,823 | 72.528±0.701 | 72.454±0.849 |
| 雷达点集单路 | 25,395 | 134.335±0.620 | 134.335±0.620 |
| 普通RGB＋点集融合 | 64,947 | **66.144±0.585** | **66.834±0.909** |
| 打乱配对训练的同结构融合 | 64,947 | 70.235±0.926 | 71.420±0.913 |

容量对照的参数量与普通融合差约0.191%。训练打乱对照每轮在训练集合内部随机重排雷达，在验证集合内部固定随机重排，保持图像与标签对应；不在训练、验证之间混用样本。

## 4. 雷达依赖干预

以下干预只在已正常训练的普通融合模型验证时进行，数值为三个种子平均。它与“打乱配对重新训练”的控制组不同。

| 验证输入 | 正常画面MPJPE | 亮度×0.18 MPJPE |
| --- | ---: | ---: |
| 正常配对 | 66.144 | 66.834 |
| 验证时随机重排雷达 | 76.300 | 77.621 |
| 验证时清空雷达并置缺失掩码 | 80.020 | 81.378 |

这些变化说明模型输出依赖雷达输入。全缺失雷达属于未训练的分布变化，不能将其当作经过训练的缺模态回退性能；它反而提示下一阶段应加入显式缺失处理与匹配的模态丢弃训练。

## 5. 时偏注入与恢复

雷达帧用原始采集时间匹配到`t+delta`，容差75ms；所有偏移均有效的共同验证集合为240帧，subject5/6/19/20分别62/60/59/59帧。保持同动作区间、非空雷达、不循环跨记录。匹配量化差中位数约27–36ms，零偏移为0。

恢复操作只还原已知人为注入配对，没有按目标姿态挑选候选。此实验不说明已经知道原生雷达—视频物理同步真值，也不把恢复后的误差定义成必然最优。负收益的计算规则保留；本轮均值中非零偏移恰好全部为正。

| 偏移 | 正常画面未恢复 | 正常恢复收益 | 亮度×0.18未恢复 | 暗条件恢复收益 |
| --- | ---: | ---: | ---: | ---: |
| −500ms | 67.968 | 1.747 | 69.392 | 2.456 |
| −200ms | 66.873 | 0.652 | 68.034 | 1.098 |
| 0ms | 66.221 | 0 | 66.936 | 0 |
| +200ms | 66.805 | 0.584 | 67.695 | 0.759 |
| +500ms | 67.804 | 1.582 | 68.931 | 1.995 |

共同240帧的恢复后平均误差分别为66.221、66.936mm。它们与主要表256帧的66.144、66.834mm不同，不能混用分母计算收益。每个种子的完整原始结果保存在运行摘要中。

## 6. 下一步的研究顺序与边界

1. 冻结并扩大训练/验证采样，检查更多动作与主体上的互补性，报告原始标签/固定筛查的敏感性。旧627帧异常候选尚未全部人工复核，不能称数据清洗已完成。
2. 在匹配预算下加入显式缺模态处理、模态丢弃训练与真实像素退化条件（曝光/噪声/遮挡等），先比较普通融合和简单质量门控。像素乘0.18几乎没有使当前视觉整体失效，不能当已解决暗光的证据。
3. 对连续或高运动开发片段测注入时偏，先做简单最近匹配、固定时移/平滑与恢复配对对照。若更完整设置中的可恢复量级仍小，研究主线转为观测可靠性与缺模态鲁棒性；若稳定扩大，再投入学习对应分布及A+B方差消融。
4. 在冻结方法和过滤协议之后再执行独立最终测试、第二数据集和更完整的预训练主体审计。当前最终测试主体`[3,10,12,18]`未用于预测或指标，不因开发结果决定删除测试样本。

上述为下一阶段计划，尚未宣称已执行。普通点集融合属于已有基线类别；现有结果支持继续研究，不构成新的算法贡献、领先性能或正式论文结论。
