# 双摄像头标定操作说明

适用青禾康养监测 0.3.1。两台摄像头应固定、并排朝向同一重叠区域。

首次使用无需导入文件。进入“双目定位”，按下面顺序完成一次真实标定。

1. **保存打印棋盘**：点击右侧“1. 保存打印棋盘”。A4 横向、100%原尺寸打印，关闭适应页面缩放，固定在平整硬板上。用尺量黑白方格边长；附带棋盘为25mm。打印尺寸改变时，在高级参数中填写实测边长。
2. **选择并连接相机**：左、右各选择一台不同设备，点击“连接双摄像头”。两路画面都要能看到整个棋盘，相机位置在采集期间保持不变。
3. **采集一组角点**：棋盘占画面约1/4到1/2，保持静止、避免反光和模糊，点击“采集一组角点”。成功后短暂显示角点，进度增加；只存角点，不保存图像。
4. **补足不同角度**：每次移动棋盘，再保持静止采集。覆盖左、右、上、下，改变远近和倾斜角度。至少12组，建议20组。相近样本会被拒绝，不必在同一位置连点。
5. **计算保存**：点击“3. 计算并保存标定”。覆盖不足时继续补采；误差偏大时清空并重新采清晰、多角度样本。成功后自动保存，并显示基线和重投影误差。
6. **导出备份**：点击上方“导出标定”，保存JSON。以后设备顺序、固定位置和分辨率一致时，可以点击“导入标定”恢复。

**10×7个方格对应9×6个内角点**。内角点是棋盘内部黑白格交叉位置，排除最外围边界；不是方格数量。附带棋盘默认9列、6行、25mm，其他棋盘参数在“高级参数”中修改。

“导出定位”导出某时刻的三维人员位置，不是标定参数，不能用于“导入标定”。默认自动保存位置为 `%LOCALAPPDATA%/CareMonitor/stereo-calibration.json`；业务资源位于EXE旁Runtime。

常见提示与处理：

- 左/右画面未检测到完整角点：检查整个棋盘同时可见，内角点数正确，焦点清晰，无反光遮挡；再调整角度或移近。
- 时间差超过50ms：保持棋盘静止，待两路图像稳定再采集。
- 样本重复：移动位置或改变距离；对不同倾斜的样本也要改变画面占比或位置。
- 覆盖不足：补采左、右、上、下位置。水平覆盖需至少20%，垂直至少15%。
- 分辨率/设备不一致：选择标定时的左右顺序和采集分辨率；移动摄像头后重新标定。

无标定时两路仍可独立检测人员，但不能提供可靠米制三维坐标。首次实机标定需要用户在两路画面中移动打印棋盘，软件不能自动生成真实参数。
